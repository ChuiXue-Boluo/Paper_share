## 二、产品目标

### 定位（一句话）
为实验室成员提供一个**按研究领域分类的论文共享与协作笔记平台**，让论文阅读沉淀为团队可复用的知识资产。

### 核心价值主张
1. **知识沉淀**：将个人论文阅读转化为团队共享知识库，避免重复劳动
2. **结构化协作**：通过共享笔记 + 论文概述预览机制，帮助成员快速判断论文价值并协作记录要点
3. **领域聚合**：按研究方向分类管理论文，降低信息检索成本

### 成功指标（可量化）

| 指标 | 定义 | 目标值 |
|------|------|--------|
| 领域覆盖率 | 已创建研究领域数 / 实验室研究方向数 | ≥ 80% |
| 论文上传量 | 累计上传论文数 | 上线 1 个月内 ≥ 50 篇 |
| 笔记活跃率 | 有共享笔记内容的论文数 / 总论文数 | ≥ 60% |
| 概述填写率 | 已填写「论文概述」的论文数 / 总论文数 | ≥ 50% |
| 周活跃成员 | 每周至少浏览/上传/编辑 1 次的成员数 | ≥ 实验室总人数 70% |

## 三、用户角色

| 角色 | 权限范围 | 说明 |
|------|----------|------|
| **访客**（Visitor） | 浏览领域、查看论文列表、查看论文概述预览、下载论文 PDF | 未登录或新成员，仅可读不可写 |
| **普通成员**（Member） | 访客权限 + 上传论文、编辑共享笔记、创建新领域 | 实验室正式成员，核心使用者 |
| **领域管理员**（Field Admin） | 普通成员权限 + 管理所属领域（编辑描述、删除领域内论文/笔记） | 领域创建者或指定负责人 |
| **系统管理员**（Admin） | 全部权限 + 用户管理、全局配置 | 实验室负责人或指定运维 |

> **说明**：MVP 阶段可先实现「普通成员」单一角色，访客为只读模式，领域管理员与系统管理员为后续迭代。

## 四、用户故事

### 普通成员

| 编号 | 用户故事 |
|------|----------|
| US-01 | 作为实验室成员，我希望**按研究领域浏览论文**，以便快速找到与我研究方向相关的论文 |
| US-02 | 作为实验室成员，我希望**上传 PDF 论文并关联到某个领域**，以便与团队成员分享我读过的好论文 |
| US-03 | 作为实验室成员，我希望**在论文列表页直接看到论文概述预览**，以便快速判断这篇论文是否值得读 |
| US-04 | 作为实验室成员，我希望**进入笔记页面使用类 Markdown 编辑器记录阅读笔记**，以便结构化地沉淀论文要点 |
| US-05 | 作为实验室成员，我希望**与所有人共享同一份笔记并可协作编辑**，以便集思广益、互相补充 |
| US-06 | 作为实验室成员，我希望**下载论文 PDF 原文**，以便离线阅读或做深度标注 |
| US-07 | 作为实验室成员，我希望**创建新的研究领域**，以便覆盖尚未归类的方向 |

### 访客

| 编号 | 用户故事 |
|------|----------|
| US-08 | 作为访客，我希望**无需登录即可浏览领域和论文概述**，以便先了解平台内容再决定是否加入 |

### 领域管理员

| 编号 | 用户故事 |
|------|----------|
| US-09 | 作为领域管理员，我希望**编辑领域描述和名称**，以便维护领域信息的准确性 |
| US-10 | 作为领域管理员，我希望**删除领域内不当或重复的论文**，以便保持领域内容质量 |

## 五、需求池

### P0 — 必须有（Must Have）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| **P0-01** | **领域浏览**：首页以卡片网格展示所有研究领域，每张卡片显示领域名称、论文数量、简要描述 | 1. 卡片按论文数量降序或创建时间排列；2. 显示「领域名 / N 篇论文 / 描述（截断）」；3. 点击卡片进入领域详情页 |
| **P0-02** | **领域详情页**：展示该领域下所有论文列表 | 1. 顶部显示领域标题与描述；2. 论文以列表/卡片形式展示；3. 每条显示标题、作者、年份、概述预览（截断 3-4 行）、下载按钮、记笔记按钮 |
| **P0-03** | **论文上传**：成员可选择领域上传 PDF 论文，填写元信息（标题、作者、发表年份、领域） | 1. 仅允许 PDF 格式（前端校验 + 后端校验）；2. 必填字段：标题、领域；3. 选填：作者、年份、摘要；4. 上传成功后出现在领域列表中 |
| **P0-04** | **论文列表概述预览**：列表页每篇论文展示「论文概述」部分内容预览 | 1. 从笔记中提取「论文概述」一级标题下的内容；2. 截断显示约 100-150 字；3. 无概述时显示「暂无概述」占位 |
| **P0-05** | **共享笔记编辑器**：网页版类 Markdown 编辑器，支持加粗、H1/H2/H3、插入图片 | 1. 工具栏含：加粗、H1、H2、H3、插入图片按钮；2. 每篇论文对应一份共享笔记（所有人共用）；3. 支持实时或分栏预览；4. 编辑内容自动保存 |
| **P0-06** | **笔记初始模板**：新建笔记时自动填充两个一级标题 | 1. 初始内容为 `# 论文概述` + 换行 + `# 阅读笔记`；2. 用户可在其下自由编辑 |
| **P0-07** | **论文下载**：列表页和笔记页均提供 PDF 下载入口 | 1. 点击下载按钮直接下载原始 PDF；2. 下载文件名使用论文标题 |
| **P0-08** | **笔记入口**：论文列表每条提供「记笔记」按钮，进入该论文的共享笔记页 | 1. 按钮位于论文卡片右侧；2. 点击跳转至笔记编辑页，URL 含论文 ID |

### P1 — 应该有（Should Have）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| **P1-01** | **创建领域**：成员可创建新研究领域，填写名称和描述 | 1. 名称唯一；2. 创建后自动成为该领域管理员；3. 创建后出现在首页 |
| **P1-02** | **论文搜索**：领域详情页支持按标题/作者关键词搜索 | 1. 输入关键词实时过滤列表；2. 匹配标题和作者字段 |
| **P1-03** | **笔记图片上传**：编辑器支持插入图片，图片存储到服务器 | 1. 点击图片按钮可选择本地图片上传；2. 支持拖拽粘贴图片；3. 图片在预览中正常显示 |
| **P1-04** | **笔记编辑历史**：记录笔记的编辑历史，支持查看历史版本 | 1. 每次保存生成一个版本；2. 可查看历史版本内容；3. 可恢复到历史版本 |
| **P1-05** | **论文元信息编辑**：上传者可编辑论文的标题、作者、年份等元信息 | 1. 上传者或管理员可编辑；2. 编辑后列表实时更新 |
| **P1-06** | **用户登录**：简单登录机制（如实验室统一账号或邮箱密码） | 1. 登录后才能上传和编辑；2. 未登录可浏览和下载 |

### P2 — 可以有（Nice to Have）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| **P2-01** | **论文标签**：除领域外，支持为论文打多个标签便于跨领域检索 | 1. 上传时可添加多个标签；2. 列表页支持按标签筛选 |
| **P2-02** | **笔记评论**：笔记页支持针对笔记内容发表评论 | 1. 可在笔记旁侧添加评论；2. 评论显示作者和时间 |
| **P2-03** | **数据统计**：首页展示平台整体数据（总论文数、总笔记数、活跃成员） | 1. 统计数据实时更新；2. 以数字卡片形式展示 |
| **P2-04** | **论文收藏**：成员可收藏感兴趣的论文，在个人页面查看 | 1. 收藏列表按时间排序；2. 可取消收藏 |
| **P2-05** | **领域管理员管理**：领域创建者可管理领域内论文（删除等） | 1. 管理员可删除领域内论文；2. 删除需二次确认 |
| **P2-06** | **暗色模式**：支持深色主题切换 | 1. 全局切换明暗主题；2. 记住用户偏好 |

```
└─────────────────────────────────────────────────────────────┘
```

**布局说明**：
- **顶部信息区**：返回按钮 + 论文标题（H1）+ 元信息 + 右侧下载 PDF 按钮
- **工具栏**（编辑器顶部固定）：
  - **加粗**（B）：选中文本点击或快捷键 Ctrl+B
  - **H1 / H2 / H3**：点击将当前行转为对应级别标题
  - **插入图片**（🖼）：点击弹出文件选择器上传图片
  - **预览开关**：切换分栏预览 / 纯编辑模式
- **编辑区（左侧）**：
  - 类 Markdown 语法输入
  - 初始内容：`# 论文概述\n\n# 阅读笔记\n`
  - 行号可选显示
  - 支持快捷键（Ctrl+B 加粗等）
- **预览区（右侧）**：
  - 实时渲染 Markdown 为 HTML
  - H1 显示为大标题加下划线分隔，H2/H3 逐级缩小
  - 加粗文字渲染为 `<strong>`
  - 图片等比例缩放显示
- **保存状态栏**（底部）：
  - 显示「已自动保存」+ 最后编辑人 + 时间
  - 自动保存间隔：5 秒或失焦时触发
- **交互行为**：
  - 所有成员共享同一份笔记，支持多人同时编辑（MVP 可为先到先编辑，P2 支持实时协同）
  - 编辑后自动保存，无需手动点击
  - 图片上传后插入 Markdown 图片语法 `![描述](url)`
